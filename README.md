# Sistema IoT Inteligente para Control y Monitoreo de Carrito

Sistema IoT desarrollado con ESP8266, Flask, WebSockets y MySQL para el control y monitoreo en tiempo real de un carrito inteligente.

---

#  Características

##  Control Inteligente

- Movimiento en tiempo real
- 11 movimientos disponibles
- Ajuste dinámico de velocidad
- Detección de obstáculos
- WebSocket bidireccional

---

## Monitoreo en Tiempo Real

- Dashboard interactivo
- Radar de obstáculos
- Historial de movimientos
- Historial de obstáculos
- Telemetría del ESP8266
- Estado del dispositivo en vivo

---

## Demos Inteligentes

- Ejecución automática de patrones
- Demos almacenadas en MySQL
- Visualización LIVE
- Secuencias dinámicas

---

# 📷 Dashboard

Sistema visual IoT con:
